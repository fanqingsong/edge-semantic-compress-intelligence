# Knowledge document examples

These files are input for the knowledge service. Supported structured case documents use one Markdown heading per incident and explicit `Summary` and `Resolution` fields. `Root cause` and `Target IP` are optional. PDF, DOCX, PPTX, and HTML files are converted with the optional MarkItDown dependency; case fields still need to be explicit for deterministic extraction.

See [docs/services/cloud/knowledge.md](../../docs/services/cloud/knowledge.md).
